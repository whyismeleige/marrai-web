## Implementation Rules

- Build sections one by one.
- Do not implement the whole homepage in one pass.
- Use the images given to you in the folders of the sections and landing-page as the visual reference.
- Use markdown files for exact copy and animation behavior.
- Do not export full screenshots as final webpage images.
- Build real React/Tailwind components.
- Use shadcn/ui defaults for primitive components.
- Do not create new spacing tokens.
- Use screenshots to match section-level spacing.

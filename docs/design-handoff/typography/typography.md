# Marrai Typography

## Fonts

UI font:
- Inter

Brand text / wordmark:
- Poppins

Do not add other fonts.

## Text Style Mapping

### Brand Text
Use for:
- Marrai wordmark only

Font:
- Poppins

### Display Text
Use for:
- Large marketing statements
- Major visual sections

Properties:
- Font: Inter
- Weight: Bold
- Line Height: 64
- Letter Spacing: -2%
- Font Size: 56 (but Flexible to Change)

### H1 Text
Use for:
- Homepage hero headline

Properties:
- Font: Inter
- Weight: Semi Bold
- Line Height: 48
- Letter Spacing: -1.5%
- Font Size: 40 (but Flexible to Change)

### H2 Text
Use for:
- Main section headings

Properties:
- Font: Inter
- Weight: Semi Bold
- Line Height: 36
- Letter Spacing: -1%
- Font Size: 28 (but Flexible to Change)

### H3 Text
Use for:
- Smaller section headings
- Card headings

Properties:
- Font: Inter
- Weight: Semi Bold
- Line Height: 28
- Letter Spacing: -0.5%
- Font Size: 20 (but Flexible to Change)

### Body Large
Use for:
- Important descriptions

Properties:
- Font: Inter
- Weight: Regular
- Line Height: 28
- Letter Spacing: 0%
- Font Size: 18 (but Flexible to Change)

### Body
Use for:
- Normal section body text

Properties:
- Font: Inter
- Weight: Regular
- Line Height: 24
- Letter Spacing: 0%
- Font Size: 15 (but Flexible to Change)

### Small
Use for:
- Small helper text

Properties:
- Font: Inter
- Weight: Regular
- Line Height: 18
- Letter Spacing: 0%
- Font Size: 13 (but Flexible to Change)

### Caption
Use for:
- Captions
- Supporting labels2

Properties:
- Font: Inter
- Weight: Regular
- Line Height: 12
- Letter Spacing: 1%
- Font Size: 12 (but Flexible to Change)

### Label
Use for:
- Eyebrows
- Small labels
- Nav helper text

Properties:
- Font: Inter
- Weight: Regular
- Line Height: 14
- Letter Spacing: 8%
- Font Size: 11 (but Flexible to Change)


### Code / Metric
Use for:
- Stats
- Metrics
- Numbers

Properties:
- Font: Inter
- Weight: Regular
- Line Height: 38
- Letter Spacing: -1%
- Font Size: 32 (but Flexible to Change)
